BUILT FOR STREAMERS

Everything your song requests need.

No viewer accounts. No bloated dashboard. Aetheris stays focused on the stream.

Twitch requests

Accept song requests from chat with configurable commands, cooldowns, automatic handling, and clear bot responses.

Spotify + YTMD

Control Spotify or YouTube Music Desktop while keeping playback on the streamer's own machine.

OBS overlays

Show current track information, requester details, progress, artwork, and polished now-playing visuals in OBS.

Cloud-connected bot

AetherisBot handles Twitch messaging while the desktop client remains the secure local playback bridge.

Queue management

See what's up next, manually accept requests, skip tracks, and keep request history organized.

Streamer controls

Themes, backups, custom responses, tray behavior, offline suppression, and practical controls without unnecessary accounts.

QUICK START

From install to first request.

1

Install Aetheris

Download the latest Windows installer and launch Aetheris.

2

Connect Twitch

Authorize your Twitch channel so AetherisBot can handle song-request messages.

3

Choose your player

Connect Spotify or enable the YouTube Music Desktop Companion Server.

4

Go live

Add the OBS overlay if you want one, enable requests, and let chat use your song-request command.
