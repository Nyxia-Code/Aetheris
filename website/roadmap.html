ROADMAP 02

TikTok Integration

A separate roadmap by design. Start barebones, prove the connection, then plug TikTok into the shared Aetheris systems.
01PLANNED MVP
Not started

TikTok Companion MVP

Connection settings, account/status display, supported TikTok LIVE connection, incoming chat, basic commands and responses, diagnostics, logging and platform identification. Official APIs, approved access or supported connectors are preferred over brittle scraping.

02PLANNED

TikTok Events

Follows, likes, shares, gifts, viewer joins, subscribers, TikTok-specific alerts and cooldowns, platform badges and a unified chat display.

03PLANNED

TikTok Automation

TikTok event triggers, OBS actions, gift thank-yous, cross-platform announcements, moderation filters, shared song requests, platform permissions and Twitch ↔ TikTok event bridges.

Example: a TikTok gift could thank the viewer, announce on Twitch, trigger OBS, play a sound and award loyalty points.

04LATER

Vertical Creator Tools

9:16 OBS presets, TikTok-safe alerts, portrait chat, vertical scenes and goals, Twitch/TikTok layout switching, dual-layout previews and automatic overlay resizing — with presets for Twitch 16:9, TikTok 9:16, YouTube vertical live and dual-stream layouts.

THE RULE

Foundation before feature count.

The immediate priority isn't to build everything at once. A reliable command-and-event engine comes first so Twitch can grow now and TikTok can join later without rebuilding Aetheris from scratch.
