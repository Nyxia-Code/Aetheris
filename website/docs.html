Commands

General options include Now-playing announcements, startup announcements, request confirmations, a Now Playing command, and a pending queue command.

Spotify and YouTube each have a playback-command master switch with presets for Skip, Pause, Resume, and Previous. Commands can be restricted to moderators and the broadcaster. Custom commands support {user}, {query}, {title}, {artist}, {source}, {queue}, {channel}, {count}, and {time}.

Spotify

Aetheris uses Spotify Authorization Code + PKCE. The app displays the redirect URI that must be registered in your Spotify developer application and stores no Client Secret.

YouTube + YouTube Music Desktop

The YouTube Data API resolves requests. YTMD's Companion Server handles local playback and realtime state. Aetheris includes playlist return/shuffle and fallback playlist handling.

OBS overlay

Theme the overlay independently under Customization → Song Overlay. The Browser Source receives sanitized Now Playing and style state through a localhost relay.

Full Setup Backup

Settings → Full setup backup exports connection settings, theme, and OBS customization. Credentials are stored in a protected Aetheris blob. Runtime queues, history, and Now Playing state are intentionally excluded.

Tray, updates & diagnostics

Closing the window hides Aetheris to the Windows tray so requests can continue. Clicking the tray icon restores it; Exit Aetheris fully shuts it down. Updates ask permission before downloading, and runtime diagnostics/error logs are available for troubleshooting.
