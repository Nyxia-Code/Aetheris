SETUP GUIDE

From zero to requests.

This guide follows the controls and terminology in Aetheris v1.4.0.

InstallTwitchSpotifyYTMDRequestsOBS

1. Install Aetheris

Download the latest stable installer, install Aetheris, and open the application. The Dashboard readiness banner tells you which services are ready.

2. Connect Twitch

Open Settings → Twitch and start the browser authorization flow. Aetheris v1.4.0 uses AetherisBot Cloud: Twitch chat reaches the cloud bot, which securely forwards requests to your paired desktop client.

Offline streamsBot messages are suppressed while the channel is offline by default. A testing override is available when you specifically need to test chat while offline.

3. Connect Spotify

In Settings, create a Spotify developer application, register the exact redirect URI Aetheris displays, paste your Spotify Client ID, then choose Connect Spotify. Aetheris uses Authorization Code with PKCE, so a Client Secret is intentionally not required or stored.

4. Or connect YouTube Music Desktop

Configure a YouTube Data API key, then install YouTube Music Desktop. In YTMD open Settings → Integrations, enable Companion Server, and connect Aetheris. Keep 127.0.0.1:9863 unless you intentionally changed it.

5. Choose request handling

On the Dashboard, Song request handling supports Manual approval, Automatic: Spotify, Automatic: YouTube, or Automatic: Spotify → YouTube. Failed automatic requests remain pending for manual handling.

6. Add the OBS overlay

Customize the Song Overlay in Aetheris, then use the Browser Source URL generated by Aetheris in OBS. The v1.4 overlay uses Aetheris's localhost relay so Spotify/YTMD credentials are not exposed in the Browser Source URL.

READY?

Open the Dashboard.

When Twitch and at least one playback source are connected, Aetheris reports that it is ready for stream.
