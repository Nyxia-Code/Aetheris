VERIFY YOUR DOWNLOAD

How to match the SHA-256 hash

A hash is a fingerprint for a file. If the hash Windows calculates for your installer exactly matches the official Installer SHA-256 shown above, you have the same file that was released.

01

Find the installer

Open the folder containing Aetheris-Setup-1.4.0.exe.

02

Open PowerShell in that folder

Click the File Explorer address bar, type powershell, and press Enter.

03

Calculate the hash

Run:

Get-FileHash ".\Aetheris-Setup-1.4.0.exe" -Algorithm SHA256
04

Compare every character

Compare the value under Hash with the official Installer SHA-256 above. Capitalization does not matter, but every letter and number must otherwise match exactly.

✓ Exact matchThe file matches the published Aetheris v1.4.0 installer hash.
✕ Different hashDo not use that installer. Delete it and download Aetheris again from the official release page.
